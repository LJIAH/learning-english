# 背单词页面趣味性优化

## 1. 动态记忆时间（按单词长度）

- 单词 ≤ 4 字母 → 10 秒
- 单词 5-7 字母 → 15 秒
- 单词 ≥ 8 字母 → 20 秒

## 2. 释义/翻译跟随模糊

单词模糊后，释义和翻译也应隐藏或半透明，真正考验记忆效果

## 3. 拼写结果动画反馈

- **全部拼对**：绿色闪烁 + 音效 + 加分飘字
- **拼错**：红色晃动 + 显示正确拼写

## 4. 星级自评 + 间隔重复

用户完成拼写后自评 1-5 星，按星级决定单词下次出现的时机

## 5. 限制"上一个"按钮

去掉或限制回退次数，防止绕过倒计时记忆机制

## 6. 混合通关机制

用户可自由前进后退复习，一组结束后根据拼写结果差异化标记：

- 全部拼对的单词 → 标记 `isMaster: true`，不再出现
- 有拼错的单词 → 不保存，下组继续回炉
- `pageNext` 仅校验当前单词是否拼完（不要求全对），防止卡死
