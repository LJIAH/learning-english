# 项目启动命令

## 可用命令

| 命令              | 说明                       |
| ----------------- | -------------------------- |
| `pnpm run web`    | 启动前端 Web 项目          |
| `pnpm run server` | 启动后端 Server 项目       |
| `pnpm run ai`     | 启动 AI 服务               |
| `pnpm run all`    | 同时启动 Web + Server + AI |

## 快捷别名（推荐）

Git Bash 中已配置别名：

- `p` = `pnpm`
- `pr` = `pnpm run`

**常用简写：**

```bash
p all          # 等价于 pnpm run all（一键启动全部）
pr web         # 等价于 pnpm run web
pr server      # 等价于 pnpm run server
pr ai          # 等价于 pnpm run ai
```
