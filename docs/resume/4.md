以下是你项目中 AI 聊天功能的整体思路梳理：

---

## 整体架构

```
前端(Vue3) ──SSE──▶ AI微服务(NestJS) ──▶ LangChain Agent ──▶ DeepSeek LLM
                                              ↕
                                      PostgreSQL(Checkpoint持久化)
```

---

## 核心思路分层

### 1. LLM 接入层 — [`llm.config.ts`](file:///g:/test/Nest/english/server/apps/ai/src/llm/llm.config.ts)

- 使用 `@langchain/deepseek` 封装 DeepSeek 模型，开启 `streaming: true`
- 使用 `@langchain/langgraph-checkpoint-postgres` 的 `PostgresSaver` 做会话持久化（checkpoint），通过 `AI_DATABASE_URL` 连接数据库并自动建表（`checkpointer.setup()`）

### 2. 多角色 Agent 层 — [`chat.service.ts`](file:///g:/test/Nest/english/server/apps/ai/src/chat/chat.service.ts)

- 模块启动时（`onModuleInit`）读取 [`prompt.mode.ts`](file:///g:/test/Nest/english/server/apps/ai/src/prompt/prompt.mode.ts) 中的 5 种角色配置（normal / master / business / qilinge / xiaoman）
- 为每个角色分别创建一个 `ReactAgent`（通过 `createAgent`），注入**独立的 systemPrompt** 和**共享的 checkpointer**
- 用 `Map<ChatRoleType, ReactAgent>` 存储，运行时按 `role` 取出对应 Agent

### 3. 会话隔离策略

- `thread_id = userId + "-" + role`：用用户ID和角色拼接作为线程标识
- 同一个用户在不同角色下有**独立的对话历史**，checkpoint 自动持久化到 PostgreSQL

### 4. 流式传输层 — [`chat.controller.ts`](file:///g:/test/Nest/english/server/apps/ai/src/chat/chat.controller.ts)

- 设置 SSE 响应头（`text/event-stream`、`no-cache`、`keep-alive`）
- 调用 `agent.stream()` 以 `streamMode: 'messages'` 获取迭代器
- `for await` 逐 chunk 写入 `res.write('data: ...\n\n')`，实时推送到前端

### 5. 前端消费层 — [`Chat/index.vue`](file:///g:/test/Nest/english/apps/web/src/views/Chat/index.vue) + [`sse/index.ts`](file:///g:/test/Nest/english/apps/web/src/apis/sse/index.ts)

- 使用 `@microsoft/fetch-event-source` 建立 SSE 连接
- 发送消息时先往列表 push 一条空的 `ai` 消息占位
- 收到每个 chunk 时累加到末尾消息的 `content`，实现**打字机效果**
- 切换角色时通过 `getChatHistory` 从后端拉取历史消息

### 6. Prompt 管理 — [`prompt.service.ts`](file:///g:/test/Nest/english/server/apps/ai/src/prompt/prompt.service.ts)

- 对外暴露 `/prompt/list` 接口，返回所有角色的 `role / label / id`（不暴露 prompt 内容），供前端渲染角色选择列表

## 数据流简图

```
用户输入 → ChatDto{role, userId, content}
              ↓
         前端 SSE POST /ai/v1/chat
              ↓
         ChatController.streamCompletion
              ↓
         ChatService → Map.get(role) → Agent
              ↓
         Agent.stream(messages, {thread_id, streamMode:'messages'})
              ↓
         DeepSeek API (流式)
              ↓
         chunk → res.write("data: {content, role:'ai'}\n\n")
              ↓
         前端 fetchEventSource.onmessage → 累加渲染
```

---

## 设计亮点

| 设计点         | 做法                                         |
| -------------- | -------------------------------------------- |
| 多角色隔离     | 每个角色独立 Agent + 独立 thread_id          |
| 历史持久化     | PostgresSaver checkpoint，服务重启不丢记录   |
| 流式输出       | SSE + `streamMode: 'messages'` 逐 token 推送 |
| Prompt 可配置  | prompt.mode.ts 集中管理，新增角色只需加一项  |
| 微服务独立部署 | AI 服务独立端口，前缀 `/ai/v1`，与主业务解耦 |
